# Component inventory

- `SiteHeader`: logo, route-aware desktop navigation, CTA, full-screen mobile menu.
- `HeroSection`: rotating editorial copy, slide controls, three-layer skewed image composition.
- `ServicesHighlightSection`: three primary service cards.
- `ValueCtaSection`: oversized positioning statement.
- `StatsSection`: three trust metrics.
- `StorySection`: local-first-timer narrative.
- `AllServicesSection`: activity/interest card grid.
- `WholesaleBenefitsSection`: three-step planning process (legacy filename retained to minimize template churn).
- `InspirationCarouselSection`: destination highlight scroller.
- `ProjectsGridSection`: culinary and trip-moment mosaic.
- `FinalCtaSection`: interactive WhatsApp trip planner.
- `InnerPageTemplate`: reusable content page for services, destinations, about, and contact.
- `ContactDetailsSection`: WhatsApp/contact detail panel.
- `SiteFooter`: route columns, brand summary, WhatsApp contact.
- `WhatsAppFab`: persistent mobile/desktop shortcut.
- `ScrollReveal`: reduced-motion-aware IntersectionObserver wrapper.
