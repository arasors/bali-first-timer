# Page topology

1. **Site header** — sticky shell; desktop navigation and a full-screen animated mobile menu.
2. **Hero** — time-driven copy/image carousel with complementary skewed photo panels and ambient gradients.
3. **Featured experiences** — three editorial cards: personal itinerary, waterfall hunting, culinary hunting.
4. **Positioning statement** — oversized dark-ocean statement and direct planning link.
5. **Trust metrics** — transparent pricing, one-to-one planning, local knowledge.
6. **Local story** — split editorial block explaining first-timer focus and clear communication.
7. **Experience directory** — visual grid for bookable interests and activities.
8. **How it works** — three-step plan, confirm, enjoy flow.
9. **Bali highlights** — horizontal image carousel using the source site's real destination imagery.
10. **Food and moments gallery** — asymmetric image grid from the source site's real culinary imagery.
11. **Trip planner CTA** — interactive trip-length/group/interests selector that composes a WhatsApp message.
12. **Footer and WhatsApp shortcut** — contact-first closing shell.

All sections are normal document flow. The header and WhatsApp action float above content. Each major section uses IntersectionObserver reveals inherited from the Flora system. The only time-driven section is the hero; the gallery carousel is user-driven with arrow controls.
