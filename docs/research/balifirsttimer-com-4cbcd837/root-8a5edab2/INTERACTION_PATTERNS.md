# Interaction patterns

- Primary actions are pill-shaped dark-ocean buttons that lift 2px on hover and expose a moving arrow.
- Secondary actions use translucent glass surfaces and lagoon borders.
- Images scale subtly on hover; text and arrows change to lagoon/leaf accents.
- Carousel controls are semantic buttons with clear labels and disabled-state styling.
- Mobile navigation uses a circular clip-path reveal and staggered item entry.
- All controls retain visible focus outlines through the shared ring token.
- `prefers-reduced-motion: reduce` removes animation and makes reveal content immediately visible.
